# 研证 · 本地科研工作台

**0.5.0 本地 Web 应用**：研究简报、Skill 科研流程、公开文献查询、用户确认阅读、候选修订、人工选题、固定随机 SVD 实验、理论论证、理论核查材料与固定原件访问，以及 SQLite 保存与导出。项目定位见 [根 README](../README.md)，理论功能见 [理论论证工作流](../docs/理论论证工作流.md)，实现与后续验收见 [技术架构](../docs/研证技术架构.md) 和 [路线图](../docs/ROADMAP.md)。

两个 Skill 的全文规则与 SHA 会进入同一个受约束的模型流程；它们不是两个独立智能体。模型建议、真实查询、用户声明的阅读与实际数值执行分别记录。

## 准备与启动

依赖锁定版本要求 **Python 3.12 或以上**（当前 NumPy 2.5.4 的最低要求），以及安装依赖所需网络。请保留完整仓库，后端需要 `skills/` 中的规则与校验器、`output/` 下运行必需的五份历史 JSON，以及 `webapp/evidence_registry_manifest.json` 引用的 35 份公开原件；不能只复制前端。

从仓库根目录运行：

```powershell
cd webapp
.\Setup-Workbench.ps1
.\Start-Workbench.ps1
```

也可以从项目根目录双击 `启动研证网站.cmd`，保留终端窗口，再打开 `http://127.0.0.1:8097/`。停止服务按 Ctrl+C。已有环境可直接运行：

```powershell
.\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8097
```

正式本机记录保存在 `webapp/data/research.db`，重启后恢复。当前仅供本地单人使用，无账户与项目权限；同源检查不代替授权。公开多用户部署需另验身份、配额、隔离、监控和备份。

演示或 Qwen/Lean 真实调用请使用独立临时库，避免触碰任何人的真实研究记录（应用在导入时创建默认库，因此必须在导入前设置）：

```powershell
$env:YANZHENG_DB_PATH = Join-Path $env:TEMP "yanzheng-demo-$(Get-Random).db"
$env:YANZHENG_MODEL_PROVIDER = "demo"
.\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8097
```

## 配置百炼千问

在 `webapp` 目录运行：

```powershell
.\Configure-Qwen.ps1
```

在本机窗口输入同一地域控制台的 OpenAI 兼容 Base URL 与 API Key，Key 输入隐藏。默认模型 `qwen-plus`；可用 `-ModelName` 指定兼容的文本模型。当前适配要求支持非思考模式和 JSON Object 输出，Base URL 以 `/compatible-mode/v1` 结尾，专属域名中的业务空间 ID 须为真实配置。

配置保存在被忽略的本机 `.env`，进程环境优先。浏览器只接收配置状态，不接收 Key；不要将凭据或研究数据库上传仓库。后端动态读取配置，保存后刷新网页状态即可；“已配置”“最近请求验证成功”“本项目实际调用过”是不同事实。

当前一次请求不重试，默认120秒超时、最多3500输出 Token；关闭模型联网和思考。用量来自服务返回，不估算费用。失败或非法结构保留输入与原候选。实际发送内容见下节。

## 研究流程与何时发起请求

1. **开始探索。** 未配置模型时使用“本地演示”，只运行规则。选择“千问 + Skill 规则”开始探索会先保存简报，再发送一次模型请求；模型可提出1—3个必要问题，也可直接给三个候选。
2. **澄清与修订。** Skill 模式提交回答、“请千问判断下一步”或提交补充资料均发起一次请求。输入先保存，失败后可重试；刷新状态不请求模型。已选题需先返回比较，最终选择仍由你决定。
3. **查文献。** 输入适合公开的关键词，选择 Crossref 或 arXiv，单轮最多5条。查询建议只填入检索词；真正执行查询依赖相应操作。成功、未命中、失败和执行状态未知均保存。
4. **记录实际阅读。** 在题录下填写读过的摘要或相关正文的摘录/笔记、准确位置并确认。程序保存用户声明和时间，不自动抓取或核实正文；接口含摘要和 PDF 链接不等于已读。
5. **据资料修订。** 主动请求千问使用材料推进流程。模型可引用真实提供的来源；科研支持/限制须来自确认阅读中的具体 `note_id`，题录只作线索。模型结果先进入待确认预览，显示阶段/候选/推荐/证据/笔记绑定变化；接受后才应用并归档旧方向，拒绝保持旧地图与选择。
6. **选题与实验。** 人工选择低秩/SVD 相关方向后，进入实验工作台调整有限参数并明确运行。固定 Worker 真正计算并保存逐次结果，下载完整 JSON 或 CSV；其他方向不支持此执行器。
7. **结果回流。** “依据结果修订”会先返回比较、清除当前选择，再请求模型分析已有结果摘要；之后需重新选择。它不自动重跑实验，失败不把旧结果改成成功。

新版流程向百炼发送简报、澄清答案、补充材料、当前候选、真实题录/API摘要、用户确认的阅读笔记，以及最近三轮有限实验摘要；两个 Skill 规则也在提示中。密钥不作为提示内容发送。阅读和实验都是待分析的资料，不能授权模型改变程序事实或自动选择。

模型根据用户阅读声明关联证据，不保证判断被原文实际支持。论文版本、定理条件、证明与实验细节仍须核查；目前阅读卡未独立锁定论文版本或内容指纹。点击小研只触发预设提示，不调用模型。

## 固定随机 SVD 实验的边界

只执行仓库固定的 `experiment_worker.py`，不接受模型/用户提供的代码、命令、文件路径或 URL。默认矩阵120×80、目标秩8、p为4/8/16、q为0/1、采样重复3次：三类各一个矩阵，共18组配置、54次随机运行、9次精确基线。可调整参数范围由后端约束，总随机运行不超过135次，单轮20秒超时。

保存算法版本、代码与矩阵哈希、构造条件、配对采样种子、逐次相对 Frobenius 误差与耗时、精确基线、数值检查和环境。方向图的执行事实不因模型分析结果而改写；实际执行记录独立保存，并关联启动时的选题快照。

三类各一个矩阵不是多个独立数据集，采样重复只衡量固定矩阵的随机性。不同p/q工作量不同，基线先测，耗时包括算法/采样/重构，不含构造/预热/误差/导出；不能据此宣称同预算优势、普遍加速或数学证明。数值不变量检查不是独立科学审稿。

当前实验为同步固定子进程和进程内锁，有超时和结束后的输出大小检查；没有持久化任务队列、取消、硬内存限额或重启恢复。进程环境移除常见凭据并请求单线程，但不是系统级沙箱。

## 保存、档案与接口

`direction_map` 使用方向契约 v1；每轮查询使用文献契约 v1。阅读笔记保留 `(run_id, source_id)`，工作流生成跨轮复合来源 ID；原始题录不随用户确认阅读而覆盖。模型调用事实与旧方向存入 `model_calls`、`direction_versions`，固定实验存入独立 `experiments`。项目 JSON 保留完整记录，计划导出包含阅读与实验摘要。

案例页只读此前资料：四篇既有阅读来源、五个架构案例，以及旧离线实验（三个矩阵、27组配置、540次随机运行、60次基线）。查看档案不计为本项目新检索、新阅读或新实验。白名单下载不开放任意服务器文件。

主要 API 包括项目创建/恢复、`/answers`、`/advance`、人工`/select`与`/reopen`、`/literature-search`、`/reading-notes`、`/experiments`及各类导出。兼容旧 `/generate` 路径仍只读取简报并要求空证据，网页新版主要使用 `/advance`。完整本机接口见 `/api/docs` 与 `/api/openapi.json`。

文献 CLI 另支持 OpenAlex、JSON/RIS 导入；网页尚未提供这些入口。当前没有复旦或其他订阅数据库自动接入。素材来源与许可见 [ASSETS.md](ASSETS.md)，前端无需外部 CDN。

## 理论核查材料与原件访问（2026-10-18）

理论工作台可明确选择案例级、卡级或既有义务级目标，追加保存不可覆盖的论断、使用假设、支持范围、推导和来源定位，并可追加明确范围的助手核查或人工意见；旧材料与旧审阅不覆盖。卡、笔记或研究背景变化时显示旧关联，409 草稿与来源字段保留，核对后显式同步。没有义务的材料显示 `not_applicable`，不创建 P2 问题卡或已接受规划；核查材料不进入模型消息，下一轮预览明确排除。

原件访问使用 `webapp/evidence_registry_manifest.json` 的固定 35 身份白名单，只按与项目材料明确关联的 `artifact_id` 显式读取，显示实际字节 SHA256、声明比对与转义纯文本预览；不开放任意路径、URL 或下载端点。旧 `unknown/not_connected` 声明保留，新读取事实单独追加；字节一致不认证来源真实性、内容正确、历史已读或数学成立。注册清单记录本机绝对根路径，非 Windows 或路径不可用环境会显示 `fixed_registry_unavailable`，不修改受保护清单字节。

人工意见只记录外部声明，不认证身份或数学正确性；四义务保持 `open`、形式状态保持 `not_formally_verified`，独立数学审阅与研究者最终决定 pending。QA `test_fixture` 回放不是真人审阅，历史归档不随仓库交付；8104 是临时 QA 预览，不是正式服务。工程测试、字节核对和固定 Lean 案例通过都不等于自然语言命题或数学结论已获认证。
