## 逐案例结论与冻结前审阅标准

### correct-feedback：正确命题及拒绝反馈

原卡的一致极限连续性命题正确。主 ε/3 路线的大部分是对的，但旧输出的反例 `gaps` 又称 `1−δ/2` 在 `δ>2` 仍在区间内，这是错误断言（例如 δ=4）；主步骤已经换成合法取点，并不能抵消另一字段的矛盾。声称邻域与 `[0,1]` 非空需要 `δ≤1` 也错误：中心 `x₀∈[0,1]` 对每个 δ>0 都在交集中。`x/n` 在该区间的上确界误差为 `1/n`，不能作为不一致收敛候选。

冻结前标准：

1. 保留正确的 statement、assumptions 和审阅/解释 target；允许提出有明确必要性的局部改写，不能为了产生 revision 而重新包装已有假设。
2. 一致收敛的 N 在 ε 之后选取且不依赖 x；随后固定 f_N，再利用其在 x₀ 的连续性选择 δ。δ 可依赖 x₀、ε 以及已固定的 N。
3. 连续性是相对定义域上的连续性，端点不需虚构区间外的函数值。不能把紧致性添加为该定理的必要条件。
4. 反例见证必须对所宣称的每个 δ>0 都属于定义域并满足严格距离条件；任一正确构造均可，不按某个固定公式评分。
5. 检查 `steps / obligations / gaps / revision_reason / search_leads` 的一致性。搜索线索中明确断言的错误数学仍是错误；真正未确认的问题可以保持开放。
6. 结构合同单独审查：历史 `f_N_continuity_applied` 不符合小写 ASCII ID 约定是结构失败，不能将其混为数学错误。

助手独立逻辑核对：若取 `t=min(δ/2,1/2)`、`x=1−t`，则 `x∈[1/2,1)` 且 `0<1−x<δ`，极限函数在该点与端点 1 的差为 1。这只是评估用的一种合法见证，不要求模型复现，也不应硬编码进通用提示。

### missing-condition：点态收敛的遗漏条件

原普遍断言为假；`f_n(x)=x^n` 满足所有原假设且点态极限在 1 不连续，旧模型识别这一点正确。端点的失败应比较区间内部的左极限和 f(1)，不能在未定义的右侧谈“左右极限不等”。一致收敛是一个充分修补条件，而非连续极限的必要条件。

旧模型关于等度连续的否定也错误：在当前紧区间，等度连续加点态收敛确实推出**整列**一致收敛，不只得到子列。若删去紧致性则须重新分析，不能将其他定义域的反例挪来反驳当前结论。[Lebl §11.6](https://www.jirka.org/ra/html/sec_arzelaascoli.html) 的 Exercises 11.6.7、11.6.9 与此直接对应。

助手独立有限覆盖核对：给定 ε>0。每个 a∈[0,1] 有一个邻域 U_a，使其中 x 对所有 n 满足 `|f_n(x)−f_n(a)|<ε/4`。令 n 趋于无穷，得到 `|f(x)−f(a)|≤ε/4`。紧致性给出有限覆盖 U_a1,…,U_am；在有限个中心用点态收敛选取共同 N，使 n≥N 时中心误差均 `<ε/4`。任意 x 落在某 U_aj，三角不等式给总误差 `<3ε/4<ε`。这同时解释了 N 为什么与 x 无关，且无需另加一致有界假设。

冻结前标准：

1. 明确原命题假，反例逐条满足定义域、每项连续、点态极限和不连续点；不能只说“有经典反例”。
2. 若提出充分条件修订，标清是待研究者接受的提议；不直接改变卡或题目选择状态。
3. 不把“一致收敛是充分条件”写成必要条件；如果谈等度连续、Dini 或 Arzelà–Ascoli，逐一核对紧致性、极限连续性、单调性等适用条件。
4. 只给了 `x^n` 反例的笔记，不足以承担修补定理的文献归因。模型可以自己推导 ε/3 证明，但应将其标作模型推导/待审阅，而非笔记已支持。
5. 不要求额外路线；少给一条无根据扩展，比带入错误扩展更适于此次流程验证。

助手独立辅助例（仅评估使用）：`h_n(x)=max(0,1−|2nx−1|)` 在 `[0,1]` 连续，逐点趋于 0，但 `h_n(1/(2n))=1`，故不一致收敛。这说明“极限连续”本身不能迫使给定函数列一致收敛。不能将旧输出中错误的 `x/n` 例子当作已成功给出这个论证。

### insufficient-evidence：真命题与证据不足

原多项式一致逼近命题为真，属 Weierstrass 逼近定理。原输入只提供“一致极限保持连续性”的定位笔记，它不能单独证明多项式逼近列的存在性。旧输出把这个证明缺口写成“逆命题不成立——连续性不能反推逼近存在性”，混淆了推理凭据不足与数学命题为假。该错误不能由随后正确的 Bernstein 候选公式抵消。

冻结前标准：

1. 同时保留“这是已知经典真命题”与“现有定位笔记不足以完成证明”两个判断，不应为了谨慎而错误否定真命题。
2. 可以识别 Bernstein 或 Stone–Weierstrass 为待查路线；未提供的具体材料不可变成已阅读的 evidence、伪造 note_id 或检索结果。
3. 若给 Bernstein 路线，必须保留核心一致收敛估计义务；若给 Stone–Weierstrass 路线，说明要核对紧致空间、实连续函数代数、分离点和含常数/不处处共同为零等前提。闭包等于 C(X,ℝ) 是结论，不能误作未解释的前提；当前实值问题无需额外复共轭条件。
4. 对 [0,1] 的多项式限制函数，常数 1 在代数中，恒等函数分离点；这些是助手对定理适用性的评估核对，不是旧模型已读资料。
5. `revision_reason` 若说无需修改，应与 revised_card 一致；不能无必要删去 target 中来源诚实的要求。
6. 允许报告“尚未完成证明/有待核查义务”；不因诚实保留未完成而判数学错误，但也不能据此计作证明完成。
