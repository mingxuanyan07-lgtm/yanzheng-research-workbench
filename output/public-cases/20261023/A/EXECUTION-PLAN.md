# 案例 A：一周 CPU 随机 SVD 复现计划

人工决定：项目作者已在本对话确认选择此方向，Codex 依授权代录。确认原文、时间、范围见 `../human-confirmation.json`。下列执行细节由制作助手细化，属于计划，不是已经完成的正式实验或原创性结论。

研究问题：固定矩阵、目标秩、过采样和随机种子后，增加子空间迭代次数能否在给定误差目标下带来值得付出的时间/访问代价？不假定增加迭代一定更划算。

论文依据：Halko 等 arXiv:0909.4061v2，PDF 第26页 §4.5 / Remark 4.3、第27页 Algorithm 4.4。它提供正交化实现的依据；本机速度、取值与实验网格是待验证的设计。原始 PDF、字符定位及 SHA-256 随案例保存。不是通读或全新检索综述。

执行入口（在项目根目录运行）：

```powershell
& .\webapp\.venv\Scripts\python.exe -X utf8 -B scripts\public_case_experiment.py --suite smoke --output output\public-cases\new-smoke
& .\webapp\.venv\Scripts\python.exe -X utf8 -B scripts\public_case_experiment.py --suite full --output output\public-cases\full-run
```

依赖：现有 Python 与 NumPy。CPU、float64、BLAS 单线程，无外部数据下载。每次使用新输出目录保留旧结果。

| 日期 | 动作 | 交付与验收 |
|---|---|---|
| 第1天 | 对照 Algorithm 4.4 实现；运行256×192冒烟 | 检查正交性小于1e-10；残差不优于精确SVD最优值（允许数值容差）；全部有限 |
| 第2天 | 固定512×384矩阵、3类谱、种子0–4；检查精确SVD参考 | 矩阵指纹和环境版本；随机方法共享同一矩阵与采样种子 |
| 第3天 | k=10/20，p=10，q=0/1/2，每组计时3次 | 90行CSV；计时含采样、QR、小SVD和重构，生成/参考/残差测量另计 |
| 第4天 | 按同误差目标（预设谱残差比≤1.10）比较中位耗时 | 报告未达阈值配置，不以删除失败组改善结果 |
| 第5天 | 另按矩阵访问代价画误差-成本曲线 | 用2q+2次块乘、块宽和主乘法量估计明确预算；不把不同q称为同预算 |
| 第6天 | 复核离群值；必要时扩大种子，保留原始数据 | 5种子只能作探索；不得将初步差异当显著性或普遍加速 |
| 第7天 | 整理复现报告，决定是否值得扩展真实数据集 | 算法/环境/边界/负结果齐全，创新性仍待单独检索核对 |

停止/收窄标准：正交性或参考残差不一致，先停下修实现；耗时波动大于方法差异，增加重复或仅报告不确定；相同误差下没有稳定收益，就保留负结果，停止“普遍更快”的目标。平台/重复奇异值只比较重构和子空间，不要求单向量逐一相同。
