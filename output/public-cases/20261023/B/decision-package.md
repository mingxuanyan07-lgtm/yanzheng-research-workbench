# 案例 B：停止原推断，收窄为 PCA 指标协议

人工决定：项目作者在本对话答复“确认 A 计划、B 收窄，按记录边界代录与录屏”。原答复保存在 `../human-confirmation.json`；Codex 代录，不伪称作者亲手点击网页或通读论文。

原目标：只凭随机 SVD 的谱范数重构误差接近最优，就验收 PCA 特征提取质量。

新目标：补充逐分量捕获方差、重构与谱间隙条件，形成有限范围的 PCA 质量检查协议。停止推进“单一残差足以验收”的一般推断。

论文：Cameron Musco 与 Christopher Musco，arXiv:1504.05477v4，2015-10-30。PDF 第3页 §2.2 讨论误差指标局限及谱平台情形，式(3)定义 per-vector error；第4页 Figure 1 展示原文的数据示例。文件哈希和精确字符定位随笔记保留。原文作者另外给出了更强的 PCA 保证，不能误写成作者没有保证。

为何收窄：原判断遗漏每个分量捕获方差的证据和适用条件。该论文的讨论直接指出指标覆盖的缺口；“没有搜到更多论文”不是收窄的依据。这也不等于随机 SVD 在所有应用中失败。

一个可复算的辅助诊断：取 A=diag(√10,√10,1)，k=1，Z=e3。谱残差平方与最优值都为10，但捕获方差仅为1，最优单分量方差为10。记录在 `../smoke/B-diagnostic.json`。这是受论文启发的3×3构造，不是原文真实数据实验的复现，也不证明某个随机SVD算法一定输出 e3。

后续可执行动作：

1. 把残差、捕获方差和逐分量误差分别定义并记录。
2. 用此构造检查验收代码，避免把残差通过当作全部通过。
3. 明确谱重复时方向不唯一；按方差/子空间验收，不强求同一向量。
4. 只有补齐条件、实现检查和有限数据验证，才继续讨论具体应用的 PCA 质量。

停止条件：若仍只能提供谱残差，停止作出 PCA 分量质量通过的结论；保留“低秩重构指标通过”这一较窄结果。当前不开展算法创新或普遍保证的主张。
